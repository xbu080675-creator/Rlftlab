dev.88：把 dev.87 的 LPL 专用首发通道升级为全球官方首发情报中心，并解决中国大陆客户端无法稳定直连海外社交网站的问题。

新增 StartingRosterFeed / StartingRosterCenter，首发逻辑不再绑定 LPL。统一支持 TEAM_SOCIAL、LEAGUE_SOCIAL、OFFICIAL_SITE、OTHER_OFFICIAL 四类官方证据；俱乐部官方社媒、赛事官方社媒与官网属于同级高可信来源，官网不再是显示门槛。若同级官方来源给出不同五人名单，不静默覆盖，直接标记冲突等待确认。

Android 客户端不直接抓 X / Instagram / YouTube / 微博页面。海外与区域官方源由云端采集/OCR 后归一化成 data/global/starting_rosters.json，APP 只拉取小型结构化证据。下载顺序优先中国大陆友好的 Gitee 只读镜像，其次 jsDelivr，最后 GitHub raw；GitHub 仍然是唯一代码/数据源真相，Gitee 仅作为分发镜像。这样国内用户无需 VPN 也能收到国际赛区首发。

全球首发证据使用赛事本地时区匹配比赛日，支持 LPL/LCK/LCP/PCS/LJL/LEC/LCS/LTA 等默认时区，并允许每条证据显式覆盖 timezone，避免用户手机时区影响 tomorrow/比赛日匹配。角色归一化支持 TOP/JUG/JGL/JUNGLE/MID/BOT/ADC/BOTTOM/SUP/SUPPORT 以及中文位置名。

首发 UI 已切换到 StartingRosterCenter，显示来源账号、平台与证据类型。旧 LplStartingRosterFeed / LplStartingRosterCenter 保留为兼容壳但不再承载实现。版本目标 1.0.0-dev.88 / versionCode 88。
