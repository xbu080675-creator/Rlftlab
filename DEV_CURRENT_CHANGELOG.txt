dev.65：修复 GitHub 更新加速“能下但太慢”的问题。更新下载不再固定押一个公共加速节点，而是在真正下载 APK 前，并发对 GitHub 直连与多个 GitHub-only 加速节点进行小范围 Range 测速，按当前用户网络的实际吞吐排序，优先选择最快路径；测速使用真实的 RiftLab Release APK，而不是只测首页延迟。下载过程中继续保留 .part 与 HTTP Range 断点续传，节点失败或实测速率明显跌破测速预期时自动保留断点并切换下一通道。大文件 APK 请求移除 Cache-Control: no-cache，允许公共反代/CDN 对版本化 Release APK 命中缓存；latest.json 仍保持 no-cache，避免检查更新拿到旧 manifest。默认节点池扩展为 GH LLKK、iSteed、XMLY、DDLC、GHFast、GHProxy.net，同时保留 GitHub 直连；所有加速仍严格限制为 RiftLab 官方 dev-latest Release 资源，不创建 VPNService、不修改系统代理、不接管其他 APP 流量。下载 UI 会显示测速选中的节点与实时 MB/s/KB/s。SHA-256、包名、versionCode 与固定开发签名校验继续强制执行。版本升级至 1.0.0-dev.65 / versionCode 65。
