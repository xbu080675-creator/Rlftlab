# RiftLab

League of Legends community esports companion app.

RiftLab 1.0 focuses on three stages of a match lifecycle:

- Pre-match: schedule, starting roster, transfers, recent rank form
- Live: real-time match data, floating RiftScreen overlay, AI live insight
- Post-match: post-game rank, player stats, key events and summaries

The app does not host or redistribute livestream video. It can open external official/community livestream pages while RiftScreen runs independently as a data overlay.

## Status

Early 1.0 development skeleton. Current live data is mocked; real data adapters are intentionally isolated behind interfaces.
